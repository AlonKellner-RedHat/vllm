# Contract: Phase 7 Scope and Milestones

## Purpose

Define completion boundaries for issue #12 and #11 and their handoff into #25.

## In Scope for Phase 7

- Real LLaDA2 model mapping and real forward implementation (#12).
- Attention strategy decision and implementation with documented fallback/limits (#11).
- Initial capability-level conformance evidence sufficient for #25 planning.

## Out of Scope for Phase 7

- Full real-weight integration closure and broad validation matrix expansion (#25 ownership).
- Global roadmap refactoring of previously completed phases.

## Completion Criteria

1. #12 deliverables produce real-model execution without mock fallback.
2. #11 deliverables provide chosen strategy, implementation, and supported/unsupported runtime matrix.
3. Conformance matrix rows exist for all Phase 7 in-scope capabilities with status and evidence/rationale.

## Handoff Criteria to #25

- Capability rows marked `pending` or `deviation` include owner and target resolution path.
- Required artifacts are linked: strategy record, runtime compatibility assertions, and conformance matrix snapshot.
